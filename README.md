# Raytracing for FullMeta

Raytracing is a FullMeta application for tracing and inspecting rays through an ideal thin lens.

## Package contents

- `catalog.json` identifies the application and declares package version `1.0.0`.
- `raytracing.schema.json` defines the application's editable schema and interface.
- `js/` contains the ray tracing implementation.
- `examples/` contains the Lens example project.
- `docs/` and `specification/` contain user and developer documentation.

Install this application through FullMeta or copy this package into the workspace's `applications/` folder. Projects created from its examples belong in the workspace's `projects/` folder.
