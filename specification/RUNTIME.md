# Runtime

**Run Study** commits pending edits, validates and saves through the shared project workflow, then traces a snapshot of the saved project. If validation or saving fails, do not run. Use the deterministic ray sampling, aperture and thin-lens equations in the [model standard](../docs/README.md). Return the source, lens and, where applicable, camera point for each ray, together with its blocked status. Save the latest successful result in the project document's optional `raytracingResult` field using `fullmeta-raytracing-result/1`. Save the model snapshot, completion time and ordered ray records with it. Do not replace the previous successful result if tracing or saving fails.

When a project opens, validate and restore its saved result into the 3D view. Compare its model snapshot with the current model; if they differ, show the old geometry and rays with a stale label. **Clear Results** asks for confirmation, then removes the saved result through the shared project save workflow and clears the displayed paths without changing the optical inputs. A new successful run replaces the previous saved result. Keep only the latest result; run history and result export are outside this example. No background execution, progress reporting or cancellation is required.
