# Simple 3D raytracing example

This specification defines a small FullMeta application that traces and displays rays from a source through one lens to a camera plane. The public [example model standard](../docs/README.md) defines its data, units and optical calculation.

Read [requirements](REQUIREMENTS.md), [UI](UI.md), [runtime](RUNTIME.md) and [acceptance](ACCEPTANCE.md) first. The other short documents describe ownership, data, validation and platform integration. Build and maintain the application schema through FullMeta's Schema Editor as described in [platform integration](PLATFORM.md). Keep the example simple and use the existing FullMeta interfaces.
